# 漫剧生图影视风格预设

> 用途：作为每张分镜图提示词的固定风格前缀，帮助统一画质、材质、光影与人物表现。先选定一种成片媒介：3D 动画、2D 动画或真人电影感。不要在同一套分镜中混用互相冲突的媒介词。

## 使用方式

```text
【固定风格预设】
【固定人物设定与参考图】
【本镜头场景、动作、表情】
竖屏9:16，中近景，人物面部清晰，构图适合手机观看
```

建议一部漫剧固定角色参考图、风格前缀、主色调、生图模型和参数。每个镜头主要改动作、表情、景别、机位和场景状态。

## 通用负面提示词

```text
低清晰度，人物脸部变形，五官不对称，多余手指，手部畸形，肢体结构错误，服装细节混乱，背景透视错误，文字乱码，水印，画风混杂，过度磨皮，过曝
```

## 选用提醒

- 3D 动画可使用建模、PBR、布料物理、数字渲染等词。
- 2D 动画应优先描述线稿、上色、笔触、阴影和纸张质感。
- 真人电影感应优先描述摄影、布光、镜头、肤质和场景真实度。
- “UE5”“8K”等词不能单独保证画质；角色参考图和整套镜头的风格一致性更关键。
