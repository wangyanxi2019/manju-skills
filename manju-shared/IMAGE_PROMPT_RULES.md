# 生图 Prompt 与设定资料分离

人物、道具、场景和四宫格的 Markdown／JSON 可以保留出处、证据等级、状态表、缺失参考图和待确认项。`items[].prompts[].text` 是直接交给生图模型的文字，只写可画出的主体、外观、材质、空间关系、当前状态、镜头与已确认风格，以及少量必要排除项。不要把资料卡逐字段拼进 Prompt。

将元数据改写为可见描述：

| 资料卡中可保留 | 生图 Prompt 中应写 |
| --- | --- |
| 面积：原文称“狭小的空间”；没有平方米数 | 狭小的室内空间；家具间距紧凑（有画面依据时） |
| 门状态：关闭；烟雾状态：无 | 南侧房门紧闭；若烟雾不影响当前画面，省略 |
| 凳子状态：原位置未说明 | 凳子不在本镜可见范围；若必须入画，先确认或设定固定位置 |
| 书桌在西北侧（待核制图约定） | 用户已接受该布局时写“西北侧书桌”；否则移出最终 Prompt |
| 未上传参考图／未被参考材料覆盖 | 写在 Prompt 外的参考素材表和待确认记录 |

场景名称可以用于索引；在 Prompt 中先给出具体环境和可见结构，避免只用“某某房间内部”之类标签诱导额外陈设。未给出的尺寸、光源角度、门轴或背面结构，不写成“不明确／未确认”让模型自行补；若非画面必需就省略，必需时先确认为生产布局。三视图缺少背面依据时，输出已知区域的方案与待补素材，不把未知区域包装成可直接生成的完整三视图。

参考图编号只与实际上传或本次明确计划挂载的图片对应。计划挂载而尚未上传的 Prompt 标为待挂载草稿，素材状态写在 Prompt 外；不要在 Prompt 末尾加入“未上传”“未核验”等句子。`@图N` 一旦正式使用，核对顺序、身份和场景状态。

每条人物 Prompt 保留具体年龄、发型、服装等画面字段，但“原文”“视觉补全设定”“适用章节”等来源标记留在资料卡。道具 Prompt 不写“精确尺寸未说明”；用已有比例或用户确认的视觉估计。空场景使用 `style_scene_prompt`，道具使用 `style_prop_prompt`，人物使用 `style_character_prompt`。必要的“无人物、无文字、水印”可保留一次，不叠加长串与画面无关的否定句。

保存 JSON 后运行 `lint_image_prompts.py` 检查可复制 Prompt，再用 `render_preview.py` 输出 HTML。检查器提示问题时，修改 Prompt 正文，同时同步 Markdown 和 JSON；出处和不确定性仍保存在各自的资料字段。
